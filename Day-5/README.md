# Face Detection using OpenCV

## 🎯 Objectives

- Learn how to use the **Haar Cascade Classifier** for face detection.
- Understand how to load a pre-trained **Haar Cascade XML file**.
- Capture live video using a **webcam**.
- Convert video frames from **BGR to grayscale**.
- Detect faces using `detectMultiScale()`.
- Draw **bounding rectangles** around detected faces.
- Display real-time face detection using OpenCV.
