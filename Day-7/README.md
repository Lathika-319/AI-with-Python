# Facial Emotion Recognition

## 🎯 Objective

Learn how to detect a face from an image and recognize the facial emotion using a pre-trained emotion recognition model.

## ✨ Key Learning Outcomes

- Detect faces from an input image.
- Recognize facial emotions using a pre-trained model.
- Process an image using CPU.
- Display the detected emotion with a bounding box.
- Save the emotion detection output.
